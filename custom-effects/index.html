Custom Effects

An effect is a class with a few hooks. It can draw many passes, keep buffers across frames, use your own textures, and draw outside the element. Every effect in @vfx-js/effects is built this way.

For a single shader, Custom Shaders is simpler. Use an effect when you want to reuse it, chain it, or share it as a package.

The Effect interface

Every member is optional.

Pass an instance as effect to vfx.add. The types come from @vfx-js/core.

shader and effect don't mix. If you set both, effect wins.

Lifecycle hooks

Hook When and what
init(ctx) Once, when the effect is added. Make render targets and wrap textures here. Can be async; vfx.add waits for it.
update(ctx) Every frame, before render. Change state here. ctx.draw does nothing here.
render(ctx) Every frame. Draw with ctx.draw and ctx.blit. Without render, the input passes through.
dispose() Once, when the element is removed. Drop your references.
outputRect(dims) The rect this effect draws into. Omit it to keep the input size.
enabled Set false to skip render. Checked every frame. init and update still run.

Every hook gets the same ctx. Its fields change every frame:

Field Value
time, deltaTime Seconds since start, and since the last frame.
src The input texture: the element, or the effect before.
target This effect's output. null means the canvas.
dims Sizes in px. See below.
mouse, mouseViewport Mouse in element px and canvas px, bottom-left origin.
intersection, enterProgress, leaveProgress, enterTime, leaveTime Scroll position and timing, like in shaders.
uniforms The uniforms option of vfx.add, evaluated every frame.
resolution, pixelRatio Canvas size in physical px, and the pixel ratio.
gl The raw WebGL2 context.

Drawing

Draw in render with ctx.draw. It runs a fragment shader over a quad. Pass ctx.src as a uniform to read the input, and set target: ctx.target to write the output.

The default vertex shader gives three in vec2 values, all 0..1:

Name Range
uvSrc 0..1 over src. Use it to read src as is.
uvContent 0..1 over the element. Outside 0..1 is the padding.
uv 0..1 over the whole output, padding included.

In a chain, src can be bigger than the element, when the effect before has padding. To move pixels around, work in uvContent and map it to src with srcRectUv, like the effects in @vfx-js/effects do:

Render targets

Make render targets in init and reuse them every frame. Draw to one, then pass it as a uniform to read it in the next draw. VFX-JS frees them when the effect is removed.

A persistent target has two buffers. As a uniform, it reads the last frame. As a target, it writes the next one. They swap after each draw.

Drawing outside the element

The overflow option does not apply to effects. Return a bigger rect from outputRect instead. It is [x, y, w, h] in physical px, relative to the element's bottom-left corner. Return dims.canvasRect to cover the whole canvas.

dims Value
element, elementPixel Element size in CSS px and physical px.
canvas, canvasPixel Canvas size in CSS px and physical px.
pixelRatio Device pixel ratio.
contentRect The element rect: [0, 0, w, h].
srcRect The rect of src: the output rect of the effect before.
canvasRect The canvas rect, relative to the element.

Textures

ctx.src and your own textures are EffectTexture handles. Pass them as uniforms. Use width and height for their size in px.

ctx.wrapTexture turns an image, canvas, video, ImageBitmap, OffscreenCanvas or WebGLTexture into a texture. Call it once in init.

  • Videos and canvases upload every frame. Other sources upload once. Change this with autoUpdate.
  • With autoUpdate: false, call texture.update() after the source changes. It uploads again on the next draw.
  • Call texture.dispose() when you replace a texture. The rest are freed when the effect is removed.
  • A WebGLTexture needs size, and update() does nothing for it.

Params

Keep settings in a public params object and read it in render. Then you can change them any time, with no re-init. The effects in @vfx-js/effects work this way. The slider in the wave demo sets params.amount.

Tips

  • Effects keep state, so don't share one instance between elements. Use a factory.
  • Render targets, wrapped textures and geometries are freed for you. In dispose, drop your references.
  • Things you make with ctx.gl are yours. Free them in dispose, and rebuild them in ctx.onContextRestored(cb).
  • Use ctx.dims for sizes. Don't read DOM sizes in render.
  • ctx.draw in update is ignored. Draw in render.
  • For bigger examples, read packages/effects/src. hue-shift.ts and pixelate.ts are short. bloom.ts uses render targets and outputRect.
