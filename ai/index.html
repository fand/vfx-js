Use with AI

Coding agents can add VFX-JS effects and write shaders for you. Give them the docs first, so they use the current API.

Install the skill

The VFX-JS skill works with Claude Code, Codex, Cursor and other agents that read skills. Run this in your project:

The agent reads it when a task needs it. It covers every package (core, React, Vue, Svelte, Astro, effects, transitions), the shader presets, custom shaders, the Effect API, transitions, and common pitfalls. The source is skills/vfx-js on GitHub.

llms.txt

No skill support? Give the agent one of these files.

  • llms.txt: a short overview, a quick start, and links to each part of the docs.
  • llms-full.txt: the whole skill in one file. Paste it into a chat, or point the agent to the URL.

Prompts that work

Name the package, the element, and the effect. Say what should happen on scroll or hover.

Write a shader with AI

  1. Describe the look in words. Ask for a VFX-JS custom shader.
  2. Paste the GLSL into vfx.add(el, { shader }).
  3. Look at it in the browser. Tell the agent what to change.

Check the result

The agent writes the code but can't watch it run. Look for these.

Console errors
A shader that fails to compile makes vfx.add reject with the GL error log and the full source. Catch it with .catch(console.error) and paste the log back to the agent.
A blank element
Usually the shader failed, the image is blocked by CORS, or the element has zero size.
Cut-off effect
A shader draws only inside the element unless you set overflow. Effects set their own room with outputRect, or a pad param on built-in ones. See Overflow.
Stale text
Text and other elements are captured once. The agent must call vfx.update(el) after the content changes. See Element capture.
Many VFX instances
Each VFX has its own WebGL context. Ask for one per page, made in client code. See Limits.
Screenshots
Agents can't see the canvas. Ask for a Playwright script that takes a screenshot. Headless browsers need WebGL on.
