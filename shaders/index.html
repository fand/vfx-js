Custom Shaders

Pass a GLSL fragment shader as shader. VFX-JS runs it over the element's box, every frame.

GLSL template

  • uv is element space: (0, 0) is bottom-left, (1, 1) is top-right.
  • Shaders are GLSL ES 3.0 by default. VFX-JS adds #version 300 es for you. Write out vec4 and texture().
  • Output is premultiplied alpha. For transparent pixels, multiply rgb by a.
  • A shader that fails to compile makes vfx.add reject with the GL error log and the full source.

Built-in uniforms

VFX-JS sets these for you. Declare only the ones you use. The full list is in Uniforms and timing.

Uniform Use it for
src The element texture.
resolution, offset Element size and origin in physical px. Use them to get uv.
time Seconds since the element was added.
mouse Mouse position, same space as gl_FragCoord.
intersection How much of the element is in the viewport, 0 to 1.
enterProgress, leaveProgress Enter and leave transitions, 0 to 1. Good for scroll reveals.
enterTime, leaveTime Seconds since the element entered or left the viewport.

Custom uniforms

Pass your own values in uniforms. A function runs every frame while the element is drawn, so use one for values that change.

JS value GLSL type
1 float
[1, 2] vec2
[1, 0, 0] vec3
[1, 0, 0, 1] vec4
new Float32Array(16) vec4 arr[4] or float arr[16]

Booleans are not supported. Use 0 and 1.

Overflow

A shader draws only inside the element unless you set overflow. There, uv goes below 0 and above 1. The texture is empty outside the element, but wrap defaults to "repeat". Check uv before you read src, or set wrap: "clamp".

See Overflow in How it Works for a diagram.

Backbuffer

Set backbuffer: true to read the previous frame as uniform sampler2D backbuffer. Use it for trails and other feedback effects.

The backbuffer covers the element plus its overflow, so read it with viewport, not offset and resolution.

Multipass

Pass an array of passes to shader. Each pass writes to a buffer named by target. Later passes read it as uniform sampler2D <target>. The last pass draws to the screen.

  • In the first pass, src is the element. In later passes, it is the previous pass. Give a pass a target to read it again later.
  • A middle pass without target gets pass0, pass1, and so on.
  • persistent: true keeps a buffer across frames. The pass reads its own last frame by its target name.
  • float: true stores values outside 0..1, like velocity. size fixes the buffer size, for small simulations.

With overflow, buffers cover more than the element. See MULTIPASS.md for how to read them, and for more examples.

Post effects

A post effect runs over the whole VFX canvas, after all elements are drawn. Set it with the postEffect option of new VFX(). It takes a preset, your own GLSL, passes, or effects.

  • src is the whole canvas. time counts from when the VFX started.
  • persistent: true gives the previous output as backbuffer.
  • It only sees what VFX-JS draws, not the rest of the page. There is no live demo here, since it would change every demo on this page.
