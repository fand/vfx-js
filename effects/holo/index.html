HoloEffect

Holographic foil from holo.spot.

This is a port of the holo.spot shaders (holospot, MIT). Huge thanks to Dmitry Kurash!

Move the pointer over it.

Overview

Turns the element into a holographic foil card. The card tilts toward the pointer and catches the light in rainbow colors. Looks copied from holo.spot work as is.

Params

Pass them to the constructor. All of them are optional. Type: HoloParams

Name Default Description
holo HoloSettingsInput | readonly HoloSettingsInput[] [] The holo.spot side: a holo.spot "Copy settings" blob, holo.spot settings with the kit's options, or a list of them applied in order over holo.spot's parameter defaults (later values win, settings merge by id, a blob starts the settings over). Set it to a new value (not changed in place) to change the scene. Default [].
sourceChannel HoloSourceChannel "alpha" Which channel of the element is read as the foil's shape: "alpha" (where it is opaque; default), "luminance" (where it is bright; the element shows where there is no foil) or "none" (the whole element rect). For emboss, whose paper is the whole card, it is how the logo image is read instead: "alpha" (holospot's: its alpha, or an opaque image's contrast against its border) or "luminance".
ink number 0 How much the element's colour tints the foil as a translucent ink, in [0, 1]. 0: bare foil (default). All materials but emboss, whose element is printed on the paper instead (emboss.printInk).
flat boolean false Keep the card flat (default false). Both are scenes holospot can draw.
sizeMm number | null Physical size of the element's largest side in mm (the foil has a real grain). null (or a value that is not a positive number): the element's CSS size at 96 dpi (1 px = 0.2646 mm). Default null.
antialias boolean true Smooth the edges of the card with 4× multisampling (MSAA) of the card target (half float), as holospot renders; the outline shows once the card turns. Default true; false saves memory (about 5× the card target's).
holo: Material
material HoloMaterial "prism" Foil material.
quality HoloQuality "medium" Quality tier (holospot's quality option). Default "medium", what holospot ships without a look; the looks set their own (object is "low").
structureScale number 1 Scale of the foil's structure, 0.25–4 (holo.spot object.structureScale; 1 = as designed): shards (shatter), flakes (nebula), dots (sparkle), the paper's tooth and the logo's relief (emboss), the relief waves. Above 1 they get smaller, below 1 larger. The gratings keep their pitch: the colours do not change, and the emboss logo keeps its size and place (emboss.x / emboss.y / emboss.width, in px).
holo: Scene
exposure number | null 0.5 Exposure in stops (EV), −3 to 3: display.ev.
tone HoloTone | null "neutral" Tone curve: display.tone.
glare number | null 0.03 Glow around bright points: the share of the light spread into it, 0–0.1: display.glare.
grain number | null 0.07 Film grain amplitude in display code values, 0–0.6; 0 turns it off: grain.amount and grain.on.
studio HoloStudio | null "studio" Light rig: studio.preset. Its lights go over the earlier ones; single lights given later win.
background string | null "#ffffff" The page behind the element, which the lighting adapts to: "black", "white" or a #rgb / #rrggbb colour: scene.background, scene.bgColor.
bow number | null 1.6 The card's bow in mm, 0–2 (the sheet sags, so the light sweeps across it): card.bow.
lens number | null 62 holospot's camera lens: focal length in mm on a 36 × 24 mm sensor, 24–200: dof.lens. It sets the field of view (62 mm is the 22° camera; shorter is wider with stronger perspective); there is no blur.
holo: Motion
pointer HoloPointer | null "tilt" What the pointer does over the element: "tilt" tilts the card, "light" moves a flashlight over it, "flash" puts the flashlight at the camera, "none" (the port's) ignores the pointer: motion.pointer.
tiltRange number | null 25 How far the pointer tilts the card, in degrees, 5–35: motion.tiltRange. It is reached at the element's edge and applies only while the pointer is over the element, unlike the tilt of GlassEffect and SwirlParticleEffect (pointer: "tilt": 20° × pointerStrength, reached half a viewport from the element's centre, wherever the pointer is on the page).
wobble boolean | null true Slow automatic tilt while the pointer is away: motion.wobble.
wobbleAmp number | null 14 The wobble's amplitude in degrees, 0–25: motion.wobbleAmp.
pose HoloVec2 | null {"x":-25,"y":-20.5} Rest pose in degrees, −35 to 35: x turns the face to the right, y tips the top edge toward the viewer: motion.pose.

API

  • new HoloEffect(initial?: Partial<HoloParams> = {}): HoloEffect
  • static readonly looks: Readonly<{ card: Readonly<{ quality: HoloQuality; settings: HoloSettings }>; image: Readonly<{ material: HoloMaterial; quality: HoloQuality; settings: HoloSettings; }>; object: Readonly<{ quality: HoloQuality; settings: HoloSettings }>; }> The looks holo.spot ships, as inputs: card (its holographic card), object (its 3D object), image (its Foil Emboss paper card; sets material: "emboss").
  • static readonly startingPoints: HoloStartingPoints The "Starting points" of holospot's material docs, as inputs (material and settings).
  • errors: any
  • ready: any
  • outputRect(dims: EffectDims): readonly [number, number, number, number] | undefined Perspective mode grows the output so the tilted card and its glare fit.
  • resolvedSettings(): Readonly<Record<string, HoloSettingValue | HoloLogo>> The settings in effect, by holo.spot id: holo.spot's defaults with settings over them, checked (clamped to the ranges, invalid values dropped).
  • setParams(updates: Partial<HoloParams>): void Assigns params, as other effects do.
  • static preload(...materials: HoloMaterial[]): Promise<void> Loads materials' code ahead of use, so switching material later draws at once.
  • static settingSpecs(material: HoloMaterial): readonly HoloSettingSpec[] The holo.spot settings a material understands (its own ids, then the scene's), for building controls.
