Effects / @vfx-js/effects

ParticleEffect

GPU particles from the pointer.

Move the pointer over it.

Overview

Emits particles around the pointer. They take the colors of the element and drift away on a swirling flow.

Params

Pass them to the constructor. All of them are optional. Type: ParticleParams

Name Default Description
Emitter
count number 1048576 Max particles. Capped at construction by the state texture size.
birthRate number 30000 Particles per second emitted within radius of the mouse while the mouse is active.
screenBirthRate number 10000 Particles per second emitted at uniform-random positions across the element. Independent of mouse motion; only gated by visibility and the same alpha-rejection as mouse spawns.
radius number 300 Spawn radius around the cursor in element px.
alphaThreshold number 0.05 Reject spawns where src.a is below this.
spawnOnIdle boolean true Emit even when the mouse is stationary.
Lifetime
life number 1 Base lifespan (sec); actual life is jittered per-particle.
alphaDecay number 5 Alpha-envelope shape exponent (>1 holds peak alpha longer; <1 sharpens fade).
fadeIn number 0.05 Fraction of life over which the particle ramps from 0 to peak alpha. Small values (≈0.05) keep the radial-emit phase visible; larger values (≈0.5) restore the slow fade-in look.
speedDecay number 1 Life-taper curve exponent (>1 holds full speed longer).
Motion
emitSpeed number 1 Initial outward speed (uv/sec, short-axis-normalized) applied to mouse-spawned particles — fades to curl-noise drift over noiseDelay. Screen-spawned particles ignore this.
noiseDelay number 0.15 Fraction of life (0..1) over which motion smoothstep-blends from the radial impulse at spawn to the curl-noise field. 0 disables the radial phase entirely.
noiseSpeed number 0.3 Curl-noise drift speed (uv/sec, short-axis-normalized) once the emit impulse decays.
noiseScale number 1 Approximate swirl size in uv units (larger → bigger swirls).
noiseAnimation number 0.3 Morph rate on the 4th simplex axis (units per second).
Appearance
pointSize number 10 Particle quad size in element px.
alpha number 1 Global alpha multiplier on each particle (0..1).
fog number 0.5 Depth fog 0..1.
color number 16777215 Base color blended into particle rgb (hex 0xRRGGBB).
colorMix number 0 Mix amount between src color (0) and color (1).
Composite
blend "add" | "normal" "add" Stamp blend mode. "add" brightens overlaps; "normal" composites with premultiplied-alpha over.
trailFade number 0.75 Per-frame trail decay (0..1). Higher = longer trails.
srcOpacity number 0 Source element opacity (0..1) shown beneath the particles.

API

  • new ParticleEffect(initial?: Partial<ParticleParams> = {}): ParticleEffect
  • maxCount: any
  • setParam(updates: Partial<ParticleParams>): void Validated bulk setter.
