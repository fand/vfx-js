Effects / @vfx-js/effects

SwirlParticleEffect

Particles curling over the extruded silhouette.

Overview

Particles flow over the shape of the element and peel off in curling wisps. The shape comes from the alpha, so use it on logos or text with a transparent background.

Params

Pass them to the constructor. All of them are optional. Type: SwirlParticleParams

Name Default Description
Particles
count number 65536 Number of particles, at most 1,048,576 (2^20), and less on a GPU whose textures are small (262,144 where they are 2048 px; a warning says so). Each particle takes up to about 180 bytes of GPU memory, so 2^20 takes about 190 MB. Live: lowering it draws fewer particles without freeing memory; raising it past what is allocated reallocates the particle state (the trails regrow, and the new particles grow in over intro).
life number 4 Mean particle lifetime in seconds (randomised ±40%).
intro number 1.5 Seconds over which the particles are born when the effect starts. Each one appears at a random moment in that window, more of them towards its end, and grows in, so the coat sprouts and the flow builds up instead of popping in whole. The first lives are shortened at random, so the particles born together don't die together.
pointSize number 1.4 Particle width in CSS px at the z = 0 plane.
streak number 0.3 Trail length, in seconds of travel. Each particle draws a curved fibre through its recent positions, tapering towards the tail. 0 draws dots. Fast particles are capped on screen at 14 particle widths per 0.3 s of streak.
Shape
sourceChannel SourceChannel "alpha" Which channel of the element is read as the silhouette: "alpha" (where it is opaque; default), "luminance" (where it is bright, so the text or the light parts of an opaque image) or "none" (the whole element rect). A change reads the element back again, like refresh().
depth number 0.22 Extrusion depth, relative to the long side of the element (= 2).
Flow
speed number 0.14 Overall flow speed, in world units per second (the long side is 2).
swirl number 1 Strength of the flow tangent to the surface.
curl number 0.8 Strength of the curl noise that makes the wisps.
curlScale number 2.2 Spatial frequency of the curl noise.
attract number 10 How strongly particles are pulled back onto the surface.
peel number 0.8 How much the pull fades with age, in [0, 1]. Old particles peel off.
Color
palette SwirlParticlePaletteName | readonly SwirlParticleColorStop[] "nebula" Particle colour gradient: a preset name or your own stops. Stops are sorted by offset, the ends clamp, and colours blend linearly. Read every frame; edits to the stops in place are picked up too.
sourceColor number 0 Mix from the palette colour (0) to the source element's colour at each particle's spawn point (1). Lighting still applies on top.
Fireflies & Bloom
fireflyRatio number 0.01 Fraction of particles drawn as bright sparkles, in [0, 1].
fireflyIntensity number 6 HDR intensity of the sparkles.
fireflyColor string "#ffd2ec" Sparkle colour, CSS hex.
bloom number 0.9 Bloom intensity. 0 turns the bloom passes off.
Light
lightDirection readonly [number, number, number] [-0.45,0.75,0.55] Direction towards the light, in view space: +x right, +y up, +z towards the viewer. It stays fixed to the screen while the camera orbits. Normalised internally.
lightColor string "#ffffff" Light colour, CSS hex. Tints the diffuse light and the glints.
lightIntensity number 1 Strength of the diffuse light. 1 is the default look.
ambient number 0.25 Light on the side facing away from the light, in [0, 1].
occlusion number 0.7 How much the creases of the shape darken, in [0, 1]. At 0.7 (the default) a fibre deep in a crease keeps 30% of its light; 0 turns the darkening off.
glint number 0.7 Strength of the glints on the fibres that face the light.
Shadow
shadow boolean false Cast a soft shadow onto the page behind the shape. The page is a plane parallel to the screen, shadowDistance behind the shape's front face, lit by lightDirection. A light from behind (z ≤ 0) casts no shadow. The shadow is clipped to the output rect (see pad). Fireflies cast none.
shadowOpacity number 0.35 Opacity of the shadow, in [0, 1].
shadowSoftness number 14 Blur radius of the shadow (gaussian sigma), in CSS px.
shadowDistance number 0.26 Distance from the shape's front face to the page behind it, in world units (the long side of the element is 2). The front face is where the front cap is when the shape is seen front-on, depth / 2 in front of its centre; the page does not turn with the shape. At 0 the page touches the front face, so only the particles that peel off towards the viewer cast a shadow; at depth it touches the back. Further means a larger offset.
shadowColor string "#1c2233" Shadow colour, CSS hex.
Camera
yaw number 0 Camera yaw in degrees. 0 looks straight at the front cap; positive turns the front cap to the right.
pitch number 0 Camera pitch in degrees. 0 looks straight at the front cap; positive turns the front cap down, showing the top.
orbitAnimation number 23 Amplitude of the orbit animation, a slow back-and-forth swing of the camera, in degrees of yaw (the pitch swings 0.3 times as far). 0 keeps the camera still (pointer drags still orbit it when drag is on).
orbitSpeed number 1 Speed of the orbitAnimation, as a multiple of the base speed: at 1, a yaw swing takes about 48 seconds. 0 holds the animation where it is. A change while it runs carries on from there.
fov number 35 Field of view in degrees, measured across the element's long side. The camera moves so the z = 0 plane keeps the element's size, so this only changes the strength of the perspective (like a dolly zoom).
zoom number 1 Camera zoom. 1 = the z = 0 plane matches the element size.
drag boolean false Orbit the camera by dragging the pointer. A drag starts on the element's box and can then leave it. While on, it listens for pointer events on window, and a drag that orbits keeps the browser from dragging the element (an image, a link) or selecting its text; UI on top of the element that should not orbit can stop pointerdown propagation.
cameraOrigin "element" | "viewport" "element" Where the camera stands:
Pointer
pointer SwirlParticlePointer "none" How the particles react to the pointer hovering over the page:
pointerRadius number 120 Radius of the pointer: "repel" hole, in CSS px on screen.
pointerStrength number 1 Strength of the pointer interaction, 0 to 100 (default 1). With the effect's pointer at "tilt", the shape turns to face the pointer by up to 20° × pointerStrength (capped at 90°), reached when the pointer is half a viewport away from the element's centre, and eases back to the rest pose once the pointer leaves the page; 0 turns it off. The tilt adds to yaw / pitch, the orbitAnimation and drags. Other pointer modes say what it does for them.
Output
pad number | "fullscreen" 200 Extra pad around the element in CSS px for the particles, bloom and shadow to draw into, or "fullscreen" to draw over the whole canvas. The default, 200, holds the wisps and the drop shadow of the default look on elements up to about 1000 px wide. A smaller pad, a larger element, zoom, a large tilt, a long shadowDistance or cameraOrigin: "viewport" on an element away from the viewport's centre clip them.
antialias boolean false Smooth the edges of the fibres with 4× multisampling (MSAA). Off by default: the particle buffer then takes about 5 times the memory, 10 times with its depth buffer, which adds up fast with a large pad or "fullscreen" on a high-DPR screen. Falls back to no multisampling, with a warning, on GPUs that can't do it.

API

  • new SwirlParticleEffect( initial?: Partial<SwirlParticleParams> = {}, opts?: SwirlParticleEffectOptions = {}, ): SwirlParticleEffect
  • refresh(): void Capture the element's silhouette again, for when its content changed: an image's src swapped, a text edit.
  • setParams(updates: Partial<SwirlParticleParams>): void
