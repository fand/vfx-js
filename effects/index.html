Effects

There are two ways to style an element. Pass a preset name to shader, or pass effect objects to effect. Use one or the other, not both.

Shader presets

@vfx-js/core comes with these presets. Pass the name to shader.

Scroll reveal presets

These animate in when the element enters the viewport, and out when it leaves. Scroll them in and out to see it again.

Preset uniforms

Some presets read values from uniforms. They have no defaults, so pass all of them.

Preset Uniforms
duotone color1, color2 (vec4), speed
tritone color1, color2, color3 (vec4), speed
hueShift shift (0 to 1)
vignette intensity, radius, power
chromatic intensity, radius, power

@vfx-js/effects

@vfx-js/effects has ready-made effects. Each one is a class. Make one instance per element.

Chaining

Pass an array to effect. Each effect reads the output of the one before it.

overflow does not apply to effects. Effects that draw outside the element, like BloomEffect, have their own pad param.

Storybook

The Storybook has every preset and effect with live controls for their params.
