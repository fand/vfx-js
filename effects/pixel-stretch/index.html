Effects / @vfx-js/effects

PixelStretchEffect

Smear one line across a band of the image.

Overview

Takes one line of pixels and stretches it across a band of the image.

Params

Pass them to the constructor. All of them are optional. Type: PixelStretchParams

Name Default Description
offset number 0 Stretch line position along the axis, in [-1, 1] (0 = center).
reach number 0.1 Height of the stretch band, as a fraction of the element.
smoothness number 0 Soften the band's edges, in [0, 1].
centerX number 0.5 Effect center X, in [0, 1].
centerY number 0.5 Effect center Y, in [0, 1].
angle number 45 Stretch direction, in degrees.

API

  • new PixelStretchEffect(initial?: Partial<PixelStretchParams> = {}): PixelStretchEffect
  • setParams(updates: Partial<PixelStretchParams>): void
