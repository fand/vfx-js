Effects / @vfx-js/effects

GlassEffect

Dispersive glass in the shape of the silhouette.

Overview

Turns the shape of the element into a block of glass. Light bends through it and splits into rainbow colors. A pattern or an image shows through from behind.

Params

Pass them to the constructor. All of them are optional. Type: GlassParams

Name Default Description
Shape
sourceChannel SourceChannel "alpha" Which channel of the element is read as the silhouette: "alpha" (where it is opaque; default), "luminance" (where it is bright, so the text or the light parts of an opaque image) or "none" (the whole element rect). A change reads the element back again, like refresh().
depth number 0.2 Extrusion depth, relative to the long side of the element (= 2).
bevel number 0.03 Size of the bevel on the edges, in the same units as depth. Most of the dispersion shows on it, where the surface turns.
bevelShape GlassBevelShape "round" Profile of the bevel.
bulge number 0 How far the caps rise in the middle, in the same units as depth. 0 keeps them flat; more makes a lens or a gem.
bulgeWidth number 0.15 Distance from the silhouette's edge over which the caps rise to the full bulge. Where the shape is narrower than twice this, the bulge has a crease along its middle.
relief number 0 Height of a relief on the front cap, in the same units as depth, from the element's luminance: positive raises the bright parts, negative the dark ones (by sinking the bright ones). It makes a button's label or a photo's content show as shape. 0 is off. Read back with the silhouette (see refresh()), so a video gives a still relief. At 0 the relief is not built; moving it off 0 reads the element back again, so the relief shows a few frames later.
reliefBlur number 0.006 How much the relief's height map is blurred, in the same units as depth. More calms a busy photo and rounds a label's edges. Changing it rebuilds the height map on the CPU.
Glass
ior number 1.5 Index of refraction at the middle of the spectrum.
dispersion number 0.12 Spread of the index of refraction over the spectrum: red is ior - dispersion / 2, violet ior + dispersion / 2. Real glass is around 0.02; 0.1 to 0.2 gives the exaggerated rainbow look.
paths number 2 Rays traced through the glass per pixel, 1 to 4, spread over the spectrum. The cost grows linearly. 2 is enough for a small dispersion; use more when the rainbow breaks up.
samples number 8 Wavelengths in the spectrum, 1 to 16. They are interpolated between the traced paths, so they are cheap. Equal to paths, the channels split into separate bands instead of a smooth rainbow.
bounces number 2 Reflections inside the glass before the ray is forced out, 0 to 5.
jitter number 0 Per-pixel offset of the wavelengths, 0 to 1. Trades the banding of a low samples for fine noise.
tint string "#ffffff" Colour of the glass, #rrggbb. Thicker glass is more saturated.
absorption number 0 How fast the glass takes its tint with thickness. 0 is clear.
reflection number 1 Strength of the reflection on the outer surface.
bump number 0 Ripples on the surface, 0 to 1, like hammered or old glass. Only the normals are bent; the outline stays the same.
bumpScale number 0.15 Size of the ripples, in the same units as depth.
frost number 0 Roughness of the surface, 0 to 1: what is seen through the glass, and reflected on it, blurs with its distance from the surface.
Backdrop
backdrop BackdropPatternName | BackdropImageSource "stripes" What is seen through the glass: a pattern name, or an image (an element, an ImageBitmap or a URL).
backdropColors BackdropPaletteName | readonly string[] "mono" The palette of a procedural pattern: a BackdropPaletteName or two or more #rrggbb colours in order, each with an equal share of the area. One colour is a flat fill. Stripes, marble bands and the flow go round the colours, the last running into the first; the grid nests them as concentric squares.
backdropVisible boolean false Draw the backdrop around the glass too, not only through it.
backdropScale number 0.25 Size of the pattern's features, or of the image, in the same units as depth.
backdropDistance number 0.6 Distance of the backdrop plane behind the shape's centre.
backdropSpeed number 0.15 Speed of the pattern, in pattern periods per second. The patterns scroll, except "marble" and "flow", which morph in place.
backdropRatio number 0.5 Share of the area that the second colour covers when the palette has two colours, 0 to 1: the width of the stripes and marble bands, of the grid's lines. Ignored for three or more colours.
backdropSoftness number 0.03 Softness of the edges between the palette's colours, 0 to 1. 0 is hard bands; near 1 the pattern is a continuous gradient through the colours.
Lights
lightIntensity number 1.5 Brightness of the soft box lights around the shape. 0 turns them off.
lightSoftness number 0.15 Softness of the lights' edges, 0 to 1.
View
yaw number 29 Camera yaw in degrees. 0 looks straight at the front cap; positive turns the front cap to the right.
pitch number 14 Camera pitch in degrees. 0 looks straight at the front cap; positive turns the front cap down, showing the top.
orbitAnimation number 20 Amplitude of the orbit animation, a slow back-and-forth swing of the camera, in degrees of yaw (the pitch swings 0.3 times as far). 0 keeps the camera still (pointer drags still orbit it when drag is on).
orbitSpeed number 3.3 Speed of the orbitAnimation, as a multiple of the base speed: at 1, a yaw swing takes about 48 seconds. 0 holds the animation where it is. A change while it runs carries on from there.
fov number 30 Field of view in degrees, measured across the element's long side. The camera moves so the z = 0 plane keeps the element's size, so this only changes the strength of the perspective (like a dolly zoom).
zoom number 0.7 Camera zoom. 1 = the z = 0 plane matches the element size.
drag boolean false Orbit the camera by dragging the pointer. A drag starts on the element's box and can then leave it. While on, it listens for pointer events on window, and a drag that orbits keeps the browser from dragging the element (an image, a link) or selecting its text; UI on top of the element that should not orbit can stop pointerdown propagation.
cameraOrigin "element" | "viewport" "element" Where the camera stands:
pointer GlassPointer "none" How the glass reacts to the pointer hovering over the page:
pointerStrength number 1 Strength of the pointer interaction, 0 to 100 (default 1). With the effect's pointer at "tilt", the shape turns to face the pointer by up to 20° × pointerStrength (capped at 90°), reached when the pointer is half a viewport away from the element's centre, and eases back to the rest pose once the pointer leaves the page; 0 turns it off. The tilt adds to yaw / pitch, the orbitAnimation and drags. Other pointer modes say what it does for them.
Output
resolution number 1 Render scale, 0.25 to 2. Below 1 is cheaper and softer; 2 supersamples the silhouette's edge.
antialias boolean true Smooth the edges with FXAA, a cheap pass over the final image. The glass is ray-marched in one pass, so multisampling would not help; the march already blends the silhouette by coverage, and FXAA smooths what is left, mostly the refraction on a narrow bevel, which changes faster than the pixels can follow. resolution: 2 is the thorough (and costly) fix.
pad number | "fullscreen" 100 Padding around the element, in CSS px, or "fullscreen" to draw on the whole canvas. Default 100. Use "fullscreen" with cameraOrigin: "viewport", where an element off the centre leans out of its rect; it costs full-canvas passes per element.
debug GlassDebugView "off" Show the cost of each pixel instead of the glass, as a heat map of SDF lookups: black 0, blue 64, green 128, yellow 192, red 256, white 320 or more.

API

  • new GlassEffect( initial?: Partial<GlassParams> = {}, opts?: GlassEffectOptions = {}, ): GlassEffect
  • refresh(): void Capture the element's silhouette again, for when its content changed: an image's src swapped, a text edit.
  • setParams(updates: Partial<GlassParams>): void
