Effects / @vfx-js/effects

ParticleExplodeEffect

One burst that shatters the element.

Click to burst.

Overview

Breaks the element into particles in one burst. Call trigger() to start it.

Params

Pass them to the constructor. All of them are optional. Type: ParticleExplodeParams

Name Default Description
Explode
count number 100000 Particle count. Hard-capped by the state texture size² (default 1M).
duration number 1 Total burst duration (sec); per-particle life is jittered.
noiseSpeed number 1.5 Curl-noise + outward-bias drift speed (uv/sec, short-axis- normalized) at full strength.
noiseScale number 1 Approximate swirl size in uv units (larger → bigger swirls).
noiseAnimation number 1 Morph rate on the 4th simplex axis (units per second).
outwardBias number 1 Radial outward push from element center, blended with curl.
speedDecay number 2 Life-taper curve exponent (>1 holds full speed longer).
Appearance
pointSize number 3 Particle quad size in element px.
alpha number 1 Global alpha multiplier on each particle (0..1).
alphaDecay number 5 Alpha-envelope shape exponent (>1 holds peak alpha longer).
fog number 0 Depth fog 0..1.
color number 16777215 Base color blended into particle rgb (hex 0xRRGGBB).
colorMix number 0 Mix amount between src color (0) and color (1).
Composite
blend "add" | "normal" "add" Stamp blend mode. "add" brightens overlaps; "normal" composites with premultiplied-alpha over.
trailFade number 0.5 Per-frame trail decay (0..1). 0 = stamp shows directly without smear; higher values leave longer trails.

API

  • new ParticleExplodeEffect(initial?: Partial<ParticleExplodeParams> = {}): ParticleExplodeEffect
  • isDone(): boolean
  • reset(): void
  • trigger(): void
