Effects / @vfx-js/effects

LightStreakEffect

Anamorphic flare and starburst streaks.

Overview

Adds light streaks to bright spots, like an anamorphic lens flare or a starburst.

Params

Pass them to the constructor. All of them are optional. Type: LightStreakParams

Name Default Description
Streaks
streaks number 2 Number of rays. 2 → a single horizontal axis (anamorphic flare); n → an n-pointed aperture starburst.
angle number 0 Base rotation of the ray fan, in degrees.
length number 300 Max streak length in CSS (logical) px.
width number 3 Streak width in CSS (logical) px — the gaussian cross-section of each streak. Thinner than the sampling grid cell and the streak breaks into stripes; raise density for thin-yet-continuous streaks.
falloff number 2 Exponential length fade decay rate. Higher concentrates the brightness into a tighter core near the source and trails a fainter tail; lower flattens toward an even streak.
density number 256 Source sampling grid dimension (instance count = density²). Higher resolves finer highlights, lets streaks be thinner without banding, and costs more vertex work (most instances are culled, so fragment cost stays tied to highlight count).
Source
threshold number 0.9 Highlight cutoff in [0,1]. Only highlights above this throw streaks.
highlightClamp number 1 Upper clamp on source highlight brightness (Blender's highlight "Maximum"), so blown-out sources don't dominate the accumulation. Floored to just above threshold; lower values have no extra effect.
Color
intensity number 0.5 Streak brightness. Drives a soft-saturating tone map (1 - exp(-acc * intensity)), so raising it brightens without clipping accumulated highlights to white.
tint readonly [number, number, number] [1,1,1] Per-channel multiplier on the streak colour.
dispersion number -0.3 Chromatic dispersion, -1..1. Gives each channel a different reach so the streak fringes through colour toward its tip. +1 lets red persist furthest (warm tip, like aperture diffraction); -1 lets blue persist (cool tip, refractive look); 0 is achromatic.
fringe number 0.5 Diffraction fringe contrast, 0..1. Periodic brightness modulation along the streak whose period scales with wavelength, so bands converge to white at the source and separate into rainbow further out. Distinct from dispersion (a monotone tip-ward shift); 0 disables it.
fringeCount number 1.5 Fringes along the streak (green channel reference); fractional.
Output
resolution number 0.2 Accumulation buffer resolution relative to the output, 0..1. Streaks are soft, so 0.5 looks nearly identical and cuts GPU bandwidth to a quarter. 1 accumulates at full resolution.
pad number | "fullscreen" 300 Extra pad around the element in CSS px so streaks aren't clipped at the element edge. Should be ≥ length. "fullscreen" reaches the viewport edges.

API

  • new LightStreakEffect(initial?: Partial<LightStreakParams> = {}): LightStreakEffect
  • setParams(updates: Partial<LightStreakParams>): void
