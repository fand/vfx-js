Effects / @vfx-js/effects

FluidEffect

Fluid simulation driven by the pointer.

Move the pointer over it.

Overview

Runs a fluid simulation on top of the element. The pointer stirs the fluid, and the fluid pushes the image around.

Params

Pass them to the constructor. All of them are optional. Type: FluidParams

Name Default Description
Simulation
simSize [number, number] [256,256] Simulation grid resolution in physical px.
pressureIterations number 1 Jacobi iterations per frame (1 is the established default).
curlStrength number 13 Vorticity confinement strength.
velocityDissipation number 0.6 Per-frame velocity decay.
densityDissipation number 0.65 Per-frame dye decay.
Splat
splatForce number 6000 Velocity injected per uv-unit of mouse motion.
splatRadius number 0.002 Velocity-splat falloff (uv² units).
dyeSplatRadius number 0.001 Dye-splat falloff (uv² units).
dyeSplatIntensity number 0.005 Dye intensity per uv-unit/sec of mouse speed.
Debug
showDye boolean false When true, output is the raw dye buffer instead of advected src.

API

  • new FluidEffect(initial?: Partial<FluidParams> = {}): FluidEffect
