Effects / @vfx-js/effects

HalftoneEffect

RGB or CMYK halftone screen.

Overview

Draws the element with dots, like print. Use RGB or CMYK screens, and set the dot size and angle.

Params

Pass them to the constructor. All of them are optional. Type: HalftoneParams

Name Default Description
Grid
gridSize number 10 Grid pitch in physical px.
dotSize number 1 Dot size relative to the cell. 1.0 = dot exactly reaches the cell corners (saturation threshold); >1.0 lets dots overlap into neighbours.
smoothing number 0.15 Soft-edge fraction of the dot radius, in [0, 1].
angle number 0 Global grid rotation in degrees, added to per-channel angles.
trimEdge boolean true Skip dots whose maximum extent would cross the image edge.
Ink
mode HalftoneMode "rgb" "rgb" (additive) or "cmyk" (subtractive ink simulation).
blackAmount number 1 How much black ink to use during CMYK separation, [0, 1]. CMYK only: 1 = max GCR (k = 1 - max(rgb)); 0 = pure CMY, no K. Lowering it preserves hue in dark regions that max-GCR would collapse to a flat K stack.
background [number, number, number, number] [0,0,0,0] SRC-OVER backdrop behind the dots, RGBA in [0, 1] (non-premul). Default [0, 0, 0, 0].
inkPalette HalftoneInkPalette {"cyan":[0.15,0.73,0.88,1],"magenta":... Per-channel inks. CMYK mode uses cyan/magenta/yellow/black, RGB mode uses red/green/blue. Each ink is [r, g, b, density], with density in [0, 1] scaling coverage independently of colour. Use HalftoneEffect.setInkPreset to apply named presets, or write into the palette directly for custom inks.

API

  • new HalftoneEffect(initial?: Partial<HalftoneParams> = {}): HalftoneEffect
  • setInkPreset(name: HalftoneInkPresetName): void Apply a named ink preset.
  • setParams(updates: Partial<HalftoneParams>): void
