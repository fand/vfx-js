Effects / @vfx-js/effects

PatternRefractionEffect

Refraction through ribbed glass.

Overview

Shows the element through ribbed or patterned glass. Pick the glass with pattern.

Params

Pass them to the constructor. All of them are optional. Type: PatternRefractionParams

Name Default Description
Pattern
pattern RefractionPattern "lenticular" Refraction pattern.
stripWidth number 0.05 Width of one strip/cell, as a fraction of the element, in (0, 1].
angle number 0 Pattern rotation, in degrees.
centerX number 0.5 Pattern center X, in [0, 1].
centerY number 0.5 Pattern center Y, in [0, 1].
edgeWrap RefractionEdgeWrap "zero" Out-of-range edge sampling.
Glass
strength number 0.5 Refraction amount.
smoothness number 0 Smooth the displacement across pattern boundaries, in [0, 1].
frost number 0 Frosted-glass jitter, in [0, 1].
dispersion number 0.04 Chromatic dispersion (per-channel refraction offset), in [0, 1].

API

  • new PatternRefractionEffect(initial?: Partial<PatternRefractionParams> = {}): PatternRefractionEffect
  • setParams(updates: Partial<PatternRefractionParams>): void
