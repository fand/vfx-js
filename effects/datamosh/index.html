Effects / @vfx-js/effects

DatamoshEffect

Fake datamosh.

Click to start or stop.

Overview

Fakes the smear of a broken video stream. The element shows as is until you call enable(). Then old pixels get dragged along with the motion. Works best on video.

Params

Pass them to the constructor. All of them are optional. Type: DatamoshParams

Name Default Description
Motion
blockSize number 16 Motion-estimation block size in px.
searchRange number 5 Motion search radius, in steps. Coverage = searchRange * searchStep px.
searchStep number 2 Pixels per search step. Widens coverage at a fixed candidate count.
useResidual boolean true Add the residual during decode (off = pure motion).
Mosh
dup number 0 P-frame duplication: re-apply the frame's motion this many extra times per frame, dragging the accumulator further along the field (the bloom/smear amplifier). 0 = one normal application.
colorSpace DatamoshColorSpace "ycbcr" Color model. "ycbcr" is 4:2:0 (half-res chroma w/ truncated MV).
chromaGain number 1 Chroma saturation boost (YCbCr output). 1 = unchanged.
Heal
healRate number 0 Chance per block per frame to refresh from the clean frame (0..1). Ramp up to heal the mosh gradually. Works with healThreshold: a block refreshes if either one hits.
healThreshold number 1 Refresh blocks whose best motion match is worse than this. Mean abs diff per channel (0..1); 1 = never.
Debug
view DatamoshView "output" Stage shown on the canvas.

API

  • new DatamoshEffect(initial?: Partial<DatamoshParams> = {}): DatamoshEffect
  • disable(): void
  • enable(): void
  • setParams(partial: Partial<DatamoshParams>): void
